FREE HOSTING:
1. Create a free GitHub account at github.com.
2. Create a new public repository, for example: jak-designs.
3. Upload index.html, style.css, script.js and the images folder.
4. Open Settings -> Pages -> Deploy from branch -> main -> /root.
5. GitHub will provide your free website address.
