JAK DESIGNS — CREATIVE PLAYGROUND WEBSITE

PACKAGE FILES
- index.html  : Main website page, homepage, design tools, colouring studio and page structure
- style.css   : Responsive Ivory White, Deep Teal and Lime Green styling and typography
- script.js   : Navigation, five print-design activities and animal/bird colouring studio
- games.js    : Five browser mini-games (XO, Memory Match, Reaction Test, Number Hunt and Snake)
- CNAME       : Custom domain setting for jakdesigns.in
- README.txt  : This publishing guide

PUBLISH TO THE EXISTING GITHUB PAGES SITE
Repository: https://github.com/JAK-Designs/JAK-Designs
Publishing branch: main

Recommended method — GitHub Desktop:
1. Download and extract this ZIP on your computer.
2. Open GitHub Desktop and clone JAK-Designs/JAK-Designs (if it is not already cloned).
3. In the cloned repository folder, replace index.html, style.css, script.js and README.txt with the matching files from this package.
4. Copy games.js into the repository root as a new file.
5. Keep the existing CNAME file containing exactly: jakdesigns.in
   (The CNAME in this package also contains jakdesigns.in; either keep the existing one or replace it with this one.)
6. Do not delete the existing gallery-*.jpg files or other repository assets.
7. In GitHub Desktop, review the changed files, enter a commit message such as "Publish JAK DESIGNS creative playground", then click Commit to main and Push origin.
8. After GitHub Pages finishes deploying, open https://jakdesigns.in and test the homepage, design tools, colouring studio and all five games on desktop and mobile.
